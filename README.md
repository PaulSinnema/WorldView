# WorldView

Interactive 3D globe in the browser: live flights, military aircraft, satellites, space telescopes, earthquakes, wildfires, launches, traffic cameras and internet radio.

Built with Blazor WebAssembly (.NET 10) and CesiumJS, deployed to GitHub Pages. New versions load automatically.
